工作区与暂存区

  • 创建文件的时候，.git 文件并不会发生任何变化，因为它是存储在工作区中的

    `echo "hello" > hello.txt`

  • 使用 git add hello.txt 去将其提交到暂存区

    • 这时候会多出一个文件 index，和一个文件夹 2a
    │  config
│  description
│  FETCH_HEAD
│  HEAD
│  index
│
├─hooks
│
├─info
│      exclude
│
├─objects
│  ├─2a
│  │      93d00994fbd8c484f38b0423b7c42e87a55d48
│  │
│  ├─info
│  └─pack
└─refs
    ├─heads
    └─tags
    • 查看文件的类型：文件的目录名称+SHA1 前面的四位
      • -t:查看对象的类型
      • -p:查看对象的内容
      • -s:查看大小
    git cat-file -t 2a93d0
# blob
git cat-file -p 2a93d0
# ÿþhello
git cat-file -s 2a93d0
    • git add 存储文件：文件类型（这里是 blob） + 文件内容，然后进行 SHA1 加密
    • 在 objects 中文件的内容会被压缩后存储到加密之后的文件中

  • 查看 index 文件，使用 git ls-files 可以查看暂存区（index）的文件情况

    git ls-files -s
# 权限      blob 对象                                        文件名
# 100644 2a93d00994fbd8c484f38b0423b7c42e87a55d48 0       hello.txt
# 100644 190b00d560cb8ac4e17678e8fccc7a2af8057bdd 0       temp.txt

git 的文件状态

  • Untrack:工作区新创建的文件。使用 git add 将文件变为 Staged
  • Modified:文件已经在 index（Staged 状态），然后在工作区修改，也可以使用 git add 变为 Staged
  • Staged:使用 git commit 将文件变为 Unmodified
